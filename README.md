# Наш уютный уголок

Сайт с часами, вехами, питомцем, заметками и баночкой комплиментов.
Записки и заметки можно писать прямо на сайте, они сохраняются на Netlify.

## Что где лежит

- `public/` — сам сайт (страница, фото, иконки)
  - `notes.js` — заметки, которые уже есть (правятся вручную)
  - `jar.js` — стартовые записки баночки
- `netlify/functions/api.mjs` и `netlify/lib/handler.mjs` — серверная часть
- `netlify.toml`, `package.json` — настройки для Netlify

## Как запустить (один раз)

1. **GitHub.** Создайте новый репозиторий (можно приватный). Нажмите
   «Add file → Upload files» и перетащите ВСЁ содержимое этой папки
   (вместе с папками `public` и `netlify`, а также `package.json`,
   `netlify.toml`, `.gitignore`). Нажмите «Commit changes».
2. **Netlify.** Откройте ваш сайт на Netlify:
   «Site configuration → Build & deploy → Continuous deployment →
   Link repository» и выберите этот репозиторий. Команду сборки
   оставьте пустой, папка публикации возьмётся из `netlify.toml`
   (`public`). Адрес сайта не изменится.
3. **Пароль.** «Site configuration → Environment variables → Add a
   variable». Имя `SITE_PASSWORD`, значение любое ваше, область действия
   обязательно с галочкой «Functions». Сохраните.
4. **Пересборка.** «Deploys → Trigger deploy → Deploy site»,
   чтобы пароль заработал.
5. Откройте сайт: на вкладке «Баночка» появится форма записки, на
   вкладке «Заметки» кнопка «Добавить заметку». При первом сохранении
   сайт спросит пароль и запомнит его на этом устройстве.

Если вместо форм ничего не появилось, откройте на Netlify
«Logs → Functions → api», там будет написана причина.

## Как это работает

- Записки и заметки хранятся в Netlify Blobs («Data & Storage → Blobs»),
  фото тоже. Перед отправкой фото уменьшаются до 1600 пикселей.
- Писать и удалять можно только с паролем. Читать может любой, у кого
  есть ссылка на сайт, так же как и ваши прежние заметки.
- Сменить пароль: поменяйте `SITE_PASSWORD` и пересоберите сайт. На
  устройствах пароль спросят заново.
- Видео через сайт добавлять нельзя, только фото. Видео кладутся в
  `public/` и подключаются в `notes.js`, как раньше.
- Заметки из `notes.js` и добавленные на сайте показываются вместе,
  по дате: новые сверху.
